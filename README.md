# Ishika Sharma | Portfolio

A personal portfolio website that showcases my skills, experience, projects and education.

**Live site:** https://ishikasharma-code.github.io/portfolio/

## Features
- Responsive layout for desktop, tablet and mobile
- Dark and light theme toggle
- Typing animation in the hero section
- Navbar that highlights the section you are viewing
- Sections: Home, About, Skills, Experience, Projects, Education and Contact
- One-click resume view
- Contact form that opens your email app

## Built with
- HTML5
- CSS3
- JavaScript (vanilla, no frameworks)

## Project structure
```
portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── photo.jpg
    └── resume.pdf
```

## Run locally
1. Clone the repository:
   `git clone https://github.com/Ishikasharma-code/portfolio.git`
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.

No installation or build step is needed.
